## `03 / featured projects`

### CampusEats — Campus Food Discovery & Review Platform
**Solo Project** · Next.js 15 · TypeScript · Supabase · PostgreSQL · Tailwind CSS · Vercel

- Built and deployed the full-stack platform for browsing campus outlets and menus and rating items across taste, hygiene, quantity and value for money.
- Implemented Supabase email/password authentication with Bennett University email validation and PostgreSQL Row-Level Security for student and admin access.
- Designed a relational schema covering profiles, outlets, menu items and ratings, with database triggers for profile creation and timestamp updates.
- Built an admin panel for managing outlets, menu items and ratings; tested with approximately 8 student accounts.

**[Repository](https://github.com/Surya-Pratap01/Campus-Eats)**

---

### Bhoomi Sanket — Land Acquisition Delay Monitoring Platform
**SIH 2026 · Team Leader · Ranked 62nd among 600+ teams in the internal round**  
Next.js 14 · TypeScript · PostgreSQL/PostGIS · Supabase · React-Leaflet · FastAPI

- Designed the monorepo architecture and shared TypeScript contracts for stage-aware land acquisition project tracking.
- Implemented project management, alerts, admin and audit-log modules using PostgreSQL/PostGIS and Supabase Row-Level Security.
- Integrated the application dashboard and GIS map into a Vercel-deployed prototype using synthetic demo data.
- Defined a FastAPI interface for future ML-based risk scoring. **ML inference is not connected and the prototype does not produce predictive scores.**
- Led the team through manual testing, final integration and the pitch; qualified for the next-stage presentation round.

**SIH 2025 · Team Leader** · Flask · Python · SQLite · SQLAlchemy · JavaScript · Leaflet.js · Chart.js

- Integrated the Flask backend with Leaflet.js mapping and Chart.js analytics views.

- Led architecture, design and final integration while collaborating on rule-based routing to six municipal departments and automatic priority assignment.
